# Trabalho 3 — Robô em Marte

Projeto acadêmico desenvolvido como parte de um trabalho da faculdade, com o objetivo de implementar a navegação de um robô em Marte utilizando algoritmos de **Pathfinding**.

## Sobre o projeto

O projeto aborda o problema de encontrar caminhos em um ambiente representado computacionalmente, simulando a navegação de um robô pela superfície de Marte.

A proposta envolve a aplicação de conceitos de algoritmos e estruturas de dados para determinar trajetórias entre diferentes posições do ambiente.

## Objetivos

- Implementar uma solução de busca de caminhos (*Pathfinding*).
- Representar computacionalmente o ambiente de navegação.
- Desenvolver a lógica de movimentação do robô.
- Aplicar conceitos de algoritmos na resolução de um problema prático.

## Conceitos abordados

- Pathfinding.
- Representação de ambientes computacionais.
- Estruturas de dados.
- Planejamento de trajetórias.


## Contexto acadêmico

Este projeto foi desenvolvido como parte de uma atividade acadêmica, com foco na aplicação prática de conceitos de programação e algoritmos.
